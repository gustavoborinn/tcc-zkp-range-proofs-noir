# Abstract

Public blockchains make contract execution auditable, but this transparency also creates a privacy problem: smart contracts often require users to expose the exact data needed to satisfy a rule. This work investigates the use of Zero-Knowledge Range Proofs to validate private attributes in Ethereum-compatible smart contracts without revealing the underlying value. The central problem is to prove that a hidden value `v` belongs to a public interval `[a, b]` while preserving confidentiality and keeping the system practical for client-side proof generation and on-chain verification.

The study develops and evaluates a Range Proof circuit in the Noir ecosystem, using ACIR as the intermediate representation and Barretenberg/UltraHonk as the proving backend. The experimental design measures the trade-off between privacy and computational cost across two main axes: the execution environment used by the prover, comparing native execution with WebAssembly (WASM32), and the cryptographic cost of range restrictions with different numeric widths, comparing a `Field` baseline with `u8`, `u32`, and `u64` variants. The evaluation considers empirical metrics, especially proving time, and deterministic metrics, including proof size, circuit complexity, backend gate count, and EVM verification cost. Gas analysis is designed for an Ethereum post-Pectra context, separating execution gas from data publication costs associated with calldata and blob-oriented scenarios.

To address latency variability in browser-based proving, the methodology adopts burn-in runs, block randomization, repeated measurements per condition, and non-parametric statistical testing with the Brunner-Munzel test, with Holm-Bonferroni correction for multiple comparisons. The work also includes negative tests to detect under-constrained circuits before performance measurement. Its main contribution is a reproducible evaluation framework for assessing whether Noir-based Range Proofs can support privacy-preserving attribute validation under the architectural constraints of WASM32 clients and EVM smart contracts.

**Keywords:** Zero-Knowledge Proofs; Range Proofs; Noir; UltraHonk; Ethereum; smart contracts; WebAssembly; privacy-preserving computation.
