## Compilação

Execute ./manuscript/build.sh na raiz. Requer Tectonic e fontes Times New Roman, Arial e Courier New; defina TCC_TECTONIC para indicar o executável. Saída: manuscript/build/main.pdf. Os arquivos das quatro tabelas já estão incluídos; compilar não exige executar experimentos.

## Alcance desta publicação

Esta branch é uma edição para leitura do orientador: fontes LaTeX, classe, tabelas, PDF e evidências resumidas. O restante do repositório herdado da main é histórico e não representa integralmente o ambiente experimental local atual. Os dados brutos, provas individuais e snapshots extensos permanecem preservados localmente; os caminhos citados no apêndice identificam esse acervo e nem todos estão disponíveis nesta publicação. Não se apresenta este pacote como reprodução experimental completa.
