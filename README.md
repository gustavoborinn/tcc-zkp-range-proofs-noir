# Validation of Private Attributes in Smart Contracts via Zero-Knowledge Proofs

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Noir](https://img.shields.io/badge/Language-Noir-black)](https://noir-lang.org/)

## 1. Overview
This repository contains the implementation and benchmarking of **Zero-Knowledge Range Proofs** using the **Noir** DSL. The project focuses on validating private user attributes (e.g., financial solvency, age verification) on public blockchains (Ethereum/Sepolia) without compromising data privacy.

The core objective is to analyze the trade-offs between privacy preservation and computational overhead (Gas costs and Proving time) when executing ZK-verifications on-chain.

## 2. Problem Statement
Public ledger transparency requires full data exposure for state transitions. This project addresses the privacy-utility paradox: proving that a hidden value $v$ satisfies $a \le v \le b$ without revealing $v$ to the network or the verifier.

## 3. Tech Stack
* **Circuit Language:** [Noir](https://noir-lang.org/) (Aztec Network)
* **Proving System:** Barretenberg (Standard Honk/Plonk)
* **Smart Contracts:** Solidity (EVM compatible)
* **Environment:** Nargo & Foundry/Hardhat

## 4. Benchmarking Methodology
The implementation is evaluated against four key metrics:
1.  **Proving Time:** Latency for witness generation and proof construction.
2.  **On-chain Verification Cost:** Gas consumption for the `verify` function in Solidity.
3.  **Circuit Complexity:** Total number of constraints generated by the Noir compiler.
4.  **Security Soundness:** Documented negative testing to ensure false proofs are rejected.
